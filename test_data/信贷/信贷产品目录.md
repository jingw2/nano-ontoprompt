# 信贷产品目录 (2026)

## 1. 消费贷（循环额度）— 产品代码 PL-RC

| 属性 | 说明 |
|------|------|
| 产品类型 | 循环额度消费贷 |
| 目标客群 | 22-55周岁，有稳定收入的工薪族、自由职业者 |
| 额度范围 | 1,000 - 300,000 元 |
| 年化利率 | 7.2% - 23.9%（按风险分层差异化定价） |
| 贷款期限 | 3/6/9/12/18/24 期 |
| 还款方式 | 等额本息 / 先息后本（优质客户可选） |
| 准入条件 | 信用评分≥500；月收入≥2,000元；非黑名单客户；年龄22-55周岁 |
| 资金方 | 众邦银行、南京银行、苏宁消费金融 |

### 定价规则
- A层客户：7.2%-12%
- B层客户：12%-18%
- C层客户：18%-23.9%
- D层客户：不授信

## 2. 消费贷（大额专项）— 产品代码 PL-LC

| 属性 | 说明 |
|------|------|
| 产品类型 | 大额专项消费贷（装修/教育/医疗/婚庆） |
| 目标客群 | 25-60周岁，有指定消费需求的优质客户 |
| 额度范围 | 50,000 - 300,000 元 |
| 年化利率 | 6.5% - 16.8% |
| 贷款期限 | 6/12/24/36 期 |
| 还款方式 | 等额本息 |
| 准入条件 | 信用评分≥650；月收入≥5,000元；须提供用途证明（装修合同/学费单/医院证明） |
| 资金方 | 锦程消费金融、浙商银行、马上消费金融 |

### 审批规则
- 金额≤10万：系统自动审批（资金方直连）
- 金额10-20万：系统初审+人工复核
- 金额>20万：风控专员审核+资金方联合审批
- IF 用途证明缺失 THEN 拒绝或降额50%

## 3. 经营贷（小微企业主）— 产品代码 BL

| 属性 | 说明 |
|------|------|
| 产品类型 | 小微企业主经营贷 |
| 目标客群 | 25-60周岁，个体工商户、小微企业法人代表 |
| 额度范围 | 50,000 - 500,000 元 |
| 年化利率 | 9.6% - 21.6% |
| 贷款期限 | 3/6/12/24 期 |
| 还款方式 | 等额本息 / 随借随还 |
| 准入条件 | 营业执照满1年；信用评分≥550；月流水≥10,000元；企业无经营异常 |
| 资金方 | 江南农商银行、南京银行、浙商银行 |

### 风控规则
- 需验证企业经营流水（近6个月银行流水）
- 个体工商户额度上限20万；有限公司上限50万
- IF 企业法人变更<6个月 THEN 暂不准入
- IF 企业有行政处罚记录 THEN 自动降额30%

## 4. 抵押贷（房产抵押）— 产品代码 ML

| 属性 | 说明 |
|------|------|
| 产品类型 | 房产抵押经营/消费贷 |
| 目标客群 | 22-65周岁，有自有房产的客户 |
| 额度范围 | 200,000 - 2,000,000 元 |
| 年化利率 | 5.4% - 12.0% |
| 贷款期限 | 12/24/36/60 期 |
| 还款方式 | 等额本息 |
| 准入条件 | 房产估值≥50万；房龄≤30年；产权清晰无纠纷 |
| 抵押率 | 住宅≤70%；商铺≤50%；办公楼≤45% |
| 资金方 | 众邦银行、江南农商银行、浙商银行 |

### 抵押率规则
- 住宅房产：抵押率上限70%
- 商铺/写字楼：抵押率上限50%
- 厂房：抵押率上限45%
- IF 房产位于一线城市 THEN 抵押率可在上限基础上+5%
- IF 客户为A层优质客户 THEN 抵押率可在上限基础上+5%

## 5. 教育分期 — 产品代码 EL

| 属性 | 说明 |
|------|------|
| 产品类型 | 教育培训分期 |
| 目标客群 | 18-45周岁，有教育培训需求的学员 |
| 额度范围 | 1,000 - 200,000 元 |
| 年化利率 | 4.5% - 13.8%（教育类优惠利率） |
| 贷款期限 | 3/6/9/12/18/24 期 |
| 还款方式 | 等额本息 |
| 准入条件 | 年龄18-45周岁；信用评分≥600；合作教育机构在读或录取 |
| 合作机构 | 新东方、中公教育、达内科技、华图教育（需在合作机构白名单中） |
| 资金方 | 苏宁消费金融、马上消费金融、锦程消费金融 |

### 特殊规则
- IF 培训周期>6个月 THEN 放款分2期（首期50%开学前，尾期50%开课后）
- IF 学员中途退学 THEN 剩余款项退回冲抵贷款余额
- IF 合作机构资质过期 THEN 暂停该机构新增业务

## 6. 购车分期 — 产品代码 AL

| 属性 | 说明 |
|------|------|
| 产品类型 | 新车/二手车分期贷款 |
| 目标客群 | 22-60周岁，有购车需求的客户 |
| 额度范围 | 50,000 - 1,000,000 元 |
| 年化利率 | 6.0% - 15.6% |
| 贷款期限 | 12/24/36/48/60 期 |
| 还款方式 | 等额本息 |
| 首付比例 | 新车≥20%；二手车≥30% |
| 准入条件 | 信用评分≥600；月收入≥4,000元；年龄22-60周岁 |
| 合作车商 | 奥迪、宝马、奔驰、丰田、比亚迪、蔚来、小鹏（签约门店） |
| 资金方 | 南京银行、浙商银行、江南农商银行 |

### 车贷规则
- 新车首付≥20%，二手车首付≥30%
- IF 车型为新能源车 THEN 利率可在基准基础上-1.5%
- IF 贷款金额>50万 THEN 须面签
- IF 车辆为二手且车龄>8年 THEN 最高贷款金额不超过10万
- IF 客户为本平台存款理财客户 THEN 首付比例可降至15%

## 产品间互斥规则

- IF 客户已有循环额度消费贷在贷余额>10万 THEN 暂停新增大额专项消费贷
- IF 客户已申请经营贷且审批通过未放款 THEN 暂不接受同时申请抵押贷
- IF 客户教育分期当前逾期 THEN 暂停所有其他产品的新增申请
- IF 客户同时申请多款产品 THEN 仅受理最新一次申请，此前申请自动关闭
- IF 客户是存量抵押贷客户 THEN 消费贷额度可在标准基础上上浮20%

## 资产组合策略

- 重资本模式（自有资金）：循环消费贷为主，占总资产包≤50%
- 轻资本模式（导流/技术服务）：经营贷+大额专项为主，重点推荐给强资金方
- 各产品在信贷资产组合中的目标占比：消费贷（循环）40%、消费贷（大额）20%、经营贷20%、抵押贷10%、分期产品10%
