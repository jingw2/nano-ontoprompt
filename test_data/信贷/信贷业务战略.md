# 信贷业务战略文件

## 1. 业务模式

奇富科技以"用先进科技改变金融服务"为使命，作为AI驱动的信贷科技平台，连接借款人与金融机构资金方，业务分为两大板块：

- **信贷驱动服务（重资本模式）**：通过自有小贷牌照直接放款，或为金融机构合作伙伴发放的贷款提供担保，公司承担部分信用风险。
- **平台服务（轻资本模式）**：仅提供获客、风控评估、资金撮合、贷后管理等技术服务，向金融机构收取服务费，不承担信用风险。

## 2. 借款人分层体系

### 2.1 信用分层规则
- **A层（优质）**：信用评分 ≥ 700，历史无逾期，授信额度可达30万元，年化利率7.2%-15%。
- **B层（良好）**：信用评分 600-699，近12个月逾期≤1次，授信额度15万元，年化利率15%-19.8%。
- **C层（一般）**：信用评分 500-599，近12个月逾期2-3次，授信额度5万元，年化利率19.8%-23.9%。
- **D层（观察）**：信用评分 < 500 或近6个月有M1+逾期，进入观察名单，暂停新增授信。

### 2.2 分层触发规则
- IF 信用评分 < 500 THEN 自动降至D层并暂停提现权限
- IF 连续3期还款正常 AND 当前层级非A层 THEN 触发升级评估
- IF 单笔逾期天数 > 90天（M3+）THEN 直接降至D层并移交催收
- IF 借款人命中反欺诈黑名单 THEN 永久拒绝授信，不受评分影响

## 3. 授信审批规则

| 授信额度区间 | 审批方式 | 时限 |
|--------|-------|-----|
| < 5万元 | 系统自动审批（风控模型直接出额） | 实时 |
| 5-15万元 | 系统初审 + 人工复核 | 2小时内 |
| 15-30万元 | 风控专员审核 + 资金方联合审批 | 1个工作日 |
| > 30万元 | 风控总监审批 + 资金方额外尽调 | 3个工作日 |

- IF 审批超时 THEN 自动升级至上一级风控人员
- IF 借款人为白名单机构员工 THEN 简化材料，审批时限压缩50%
- IF 多头借贷指标（近3个月申请机构数）> 5家 THEN 触发人工复核，不予自动通过

## 4. 资金方合作规则
- IF 资金方授信额度使用率 > 90% THEN 触发资金调配预警，自动匹配备用资金方
- IF 单一资金方合作占比 > 40% THEN 启动分散化管理，暂停新增撮合额度
- IF 资金方要求的风险准备金覆盖率 < 合同约定值 THEN 暂停该资金方新增放款，直至补足

## 5. 贷后管理与催收规则

### 5.1 逾期分级
| 逾期阶段 | 逾期天数 | 催收方式 |
|--------|--------|--------|
| M0（当期） | 1-30天 | 短信+APP提醒 |
| M1 | 31-60天 | 电话催收 |
| M2 | 61-90天 | 委外催收+征信预警通知 |
| M3+ | 90天以上 | 委外催收+法务介入+征信上报 |

- IF 逾期天数 > 30天 THEN 自动转入电话催收队列
- IF 逾期天数 > 90天 THEN 强制上报征信并启动法务流程
- IF 借款人主动结清逾期欠款 THEN 更新信用评分并解除催收标记
- IF 催收记录中借款人失联 > 15天 THEN 触发失联修复流程，联系紧急联系人

## 6. 合规与风险准备金
- 风险准备金覆盖率需维持在在贷余额的3%以上，低于此比例触发资金侧预警
- IF 单月新增不良贷款率（M3+占比）> 5% THEN 收紧该渠道获客策略并上报风控委员会
- IF 监管新规发布 THEN 合规部需在15个工作日内完成业务规则适配评估

## 7. 获客策略

### 7.1 渠道分层
| 渠道类型 | 渠道来源 | 获客成本(元/人) | 平均信用分层 | 目标占比 |
|---------|---------|---------------|-----------|--------|
| 线上广告 | 抖音/头条/微信/百度 | 80-150 | B-C层 | 35% |
| 线下推广 | 地铁/商圈/社区地推 | 120-200 | C-D层 | 15% |
| 合作导流 | 手机厂商/电商平台/生活服务APP | 50-100 | A-B层 | 20% |
| 自然流量 | 品牌搜索/口碑推荐/APP商店 | 10-30 | A-B层 | 15% |
| 存量复贷 | 历史借款客户 | 5-15 | A-C层 | 15% |

### 7.2 渠道管理规则
- IF 单一渠道获客成本 > 渠道历史均值×1.5倍 THEN 暂停该渠道投放，分析成本上升原因
- IF 渠道转化率 < 0.5%（展示→申请） THEN 优化渠道素材或降低该渠道预算权重
- IF 渠道引入客户的不良率 > 行业均值×1.2 THEN 收紧该渠道准入规则（提高评分门槛50分）
- IF 线上广告渠道的日消耗 > 预算上限 THEN 触发消耗预警，自动下调出价
- IF 客户通过存量复贷渠道申请 THEN 走快速审批通道，无需重复认证

### 7.3 转化漏斗
- 曝光→点击：线上广告平均点击率CTR 2.5%-4.0%
- 点击→注册：落地页转化率 15%-25%
- 注册→申请：平均 30%-45%（受额度试算工具影响，预授信展示可提升申请转化率15%）
- 申请→审批通过：整体 55%-75%（因渠道和分层差异）
- 审批通过→签约放款：整体 82%-92%（面签环节漏斗最大）

## 8. 产品定价策略

### 8.1 风险定价模型
- 定价基准 = 资金成本 + 风险溢价 + 运营成本 + 目标利润率
- 资金成本：重资本模式下 3.5%-6.0%（视资金方和期限），轻资本模式下无资金成本
- 风险溢价 = PD（违约概率）× LGD（违约损失率）× 1.5（含资本占用缓冲）
- 运营成本率：固定 2.5%（含系统/人力/风控/客服分摊）
- 目标利润率：3%-5%（A层走量薄利，C层风险溢价高）

### 8.2 分层定价规则
- A层客户：APR 7.2%-15%，重点获取LTV（生命周期价值），引导复贷
- B层客户：APR 15%-19.8%，平衡风险和收益，关注D30+逾期转化
- C层客户：APR 19.8%-23.9%，高风险高定价，严格额度管控，重点控制不良
- D层客户：不授信，引导修复信用后重新评估

### 8.3 动态定价调整
- IF 客户历史还款连续6期正常 THEN 自动降价0.5%（行为激励）
- IF 客户为复贷且历史无逾期 THEN 利率在基准上-1.5%
- IF 借款金额>20万 THEN 规模优惠0.5%
- IF 客户在本平台有存款/理财 THEN 利率在基准上-1%
- IF 资金方为抢占市场份额调整报价 THEN 平台层定价策略联动调整

## 9. 客户全生命周期管理

### 9.1 生命周期阶段
| 阶段 | 定义 | 运营策略 | 考核指标 |
|------|------|---------|---------|
| 导入期 | 注册30天内未借款 | 预授信推送 + 首借优惠 | 首借转化率≥25% |
| 成长期 | 已借款1-3笔，按时还款 | 额度提升 + 利率优化 | 复贷率≥45% |
| 成熟期 | 借款≥4笔，信用良好 | 交叉销售（多产品覆盖） | 户均产品数≥1.5 |
| 衰退期 | 12个月未借款 | 唤醒优惠 + 重新评估 | 唤醒率≥18% |

### 9.2 新客转化规则
- IF 新客注册24小时内未完成申请 THEN 触发首借优惠PUSH（免息券/提额券，有效期7天）
- IF 新客完成授信但7天内未支用 THEN 发送专属利率折扣（首笔利率8折）
- IF 新客注册后完成身份认证 BUT 未提交授信申请 THEN 推送模拟额度试算工具
- IF 新客首次借款成功 THEN 进入成长期管理体系

### 9.3 存量运营规则
- IF 优质客户（A层+连续6期还款正常）即将到期结清 THEN 提前15天推送复贷预审批额度
- IF 客户当前借款即将还清 AND 额度使用率>80% THEN 触发自动提额评估
- IF 客户在贷余额<授信额度的10%超过3个月 THEN 主动降额至在贷额度120%
- IF 客户被降层（A→B/B→C） THEN 发送信用改进建议和修复计划

### 9.4 流失预警与召回
- IF 客户额度使用率连续下降超过50% THEN 触发流失预警，调研原因
- IF 客户12个月未借款（睡眠）THEN 重新拉取征信，重新评估授信
- IF 客户已结清所有借款且评分未下降 THEN 授信有效期内可直接支用
- IF 睡眠客户回归后首次借款<5,000元 THEN 自动审批+新客优惠利率

## 10. 资金方合作策略

### 10.1 合作模式对比
| 维度 | 重资本模式 | 轻资本模式 | 混合模式 |
|------|-----------|-----------|---------|
| 信用风险承担 | 平台承担部分 | 资金方全额承担 | 按比例分担 |
| 收入结构 | 利息收入 | 技术服务费 | 利息+服务费 |
| 资金成本 | 3.5%-6.0% | 无（资金方出钱） | 部分成本 |
| 资本占用 | 高（需小贷牌照） | 低（无需资本占用） | 中等 |
| 利润率 | 6%-12%（高风险高收益） | 2%-5%（稳定但薄利） | 4%-8% |
| 可扩展性 | 受资本金约束 | 高（理论上限更高） | 中等 |

### 10.2 资金方准入规则
- 重资本合作方：银行/消费金融公司，注册资本≥10亿，不良率<3%
- 轻资本合作方：银行/消费金融公司/信托，具备独立风控能力和系统直连条件
- IF 资金方合作年限<1年 THEN 初始额度不超过该资金方总授信的20%，逐年放开
- IF 资金方连续3个月审批通过率<50% THEN 启动合作评估，可能降低合作等级
- IF 资金方出现监管处罚/股东变更/核心风控团队离职 THEN 暂停新增撮合

### 10.3 资金方限额规则
- 单一资金方合作敞口不超过平台总撮合量的40%
- 前三大资金方合计敞口不超过平台总撮合量的75%
- IF 单一资金方敞口使用率>90% THEN 自动切换部分流量至备用资金方
- IF 重资本资金方风险准备金覆盖率<合同约定值 THEN 暂停该渠道新增放款
- IF 资金方日均放款时效>T+2 THEN 降低路由优先级
