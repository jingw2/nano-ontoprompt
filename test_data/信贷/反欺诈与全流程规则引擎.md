# 反欺诈与全流程规则引擎 — 奇富科技风控体系

本规则引擎覆盖信贷业务全生命周期，所有规则按处理阶段分类并编号，便于本体抽取和规则追溯。

---

## 1. 入口反欺诈规则 (AC)

### 1.1 设备指纹检测
- AC-001: IF 设备ID在黑名单 OR 设备近期关联3个以上不同借款账号 THEN 直接拒绝
- AC-002: IF 设备IP归属地与申请填写的城市距离>500km AND 无合理解释 THEN 触发欺诈标记+人工核验
- AC-003: IF 同一设备1小时内申请>5次 THEN 触发频次限制，拒绝并标记异常
- AC-004: IF 设备为模拟器/ROOT/越狱状态 THEN 大幅降权至D层（即使高评分也仅限极小额度）

### 1.2 身份核验
- AC-005: IF 身份证号码与公安系统返回不一致 THEN 拒绝并记录身份冒用嫌疑
- AC-006: IF 人脸比对分数<0.75 THEN 拒绝（活体检测不通过）
- AC-007: IF 银行卡四要素（姓名/身份证/手机号/银行卡号）校验失败 THEN 拒绝
- AC-008: IF 申请手机号使用时长<3个月 THEN 触发额外验证（通话详单+社交关系确认）

### 1.3 黑名单检测
- AC-009: IF 借款人命中失信被执行人名单 THEN 永久拒绝，不受评分影响
- AC-010: IF 借款人命中关联黑名单（担保人/亲属被列入黑名单） THEN 标记观察，进入人工审核通道
- AC-011: IF 借款人命中同业逃废债共享黑名单 THEN 永久拒绝并同步至联合惩戒平台
- AC-012: IF 借款人命中平台内部历史欺诈标记 THEN 账户冻结，推送反欺诈中心核查

### 1.4 团伙欺诈检测
- AC-013: IF 同一收货地址关联3个以上借款人ID THEN 标记团伙欺诈嫌疑，统一人工核查
- AC-014: IF 同一紧急联系人关联5个以上借款人 THEN 触发联系人聚类分析
- AC-015: IF 借款人在申请时段内与已知欺诈团伙存在通话记录或位置交集 THEN 自动拒绝并上报

## 2. 授信审批规则 (CR)

### 2.1 评分卡决策
- CR-001: IF 外部征信评分（人行征信/百行征信）≥700 AND 平台内部评分≥650 THEN 系统自动通过
- CR-002: IF 外部征信评分<500 OR 平台内部评分<450 THEN 系统自动拒绝
- CR-003: IF 外部征信评分与内部评分偏差>150分 THEN 触发人审（可能为数据不一致或信息造假）
- CR-004: IF 半年内征信查询次数>12次 THEN 多头借贷风险标记，降一档处理
- CR-005: IF 征信报告中存在次级/可疑/损失类贷款记录 THEN 拒绝
- CR-006: IF 客户为白名单机构员工（如腾讯/阿里/华为/政府机关）THEN 简化材料，额度上浮20%

### 2.2 收入与负债评估
- CR-007: IF 负债收入比（DTI）>50% THEN 降额50%或拒绝（视信用分层）
- CR-008: IF 月还款额（含本笔）>借款人月收入的60% THEN 自动拒绝
- CR-009: IF 借款人未提供收入证明或收入证明存疑 THEN 以政策默认收入为基准（一线城市8,000/二线5,000/三线3,000）
- CR-010: IF 公积金缴纳基数>15,000/月 THEN 收入认定可按公积金基数×1.5倍（优质客户通道）

### 2.3 额度试算
- CR-011: 授信额度 = MIN(收入倍数法额度 × 信用系数, 资金方定额上限)
- CR-012: 收入倍数法额度 = 月收入 × (36 - 在贷月还款额占比×10)  — 稳定工薪族最大36倍
- CR-013: 信用系数 = A层1.0 / B层0.7 / C层0.4 / D层0
- CR-014: IF 借款人有多头借贷（近3个月申请机构>5家）AND 信用分层非A层 THEN 授信额度在试算基础上再打7折
- CR-015: IF 借款人首次借款成功且按时还款3期以上 THEN 触发自动提额评估（提额幅度10-30%）

## 3. 资金匹配规则 (FM)

### 3.1 资金方路由
- FM-001: IF 客户分层为A层 AND 借款金额≤10万 THEN 优先匹配对A层客户有利率优惠的资金方
- FM-002: IF 客户分层为C层 AND 借款金额≤5万 THEN 匹配接受C层的资金方（利率较高）
- FM-003: IF 客户分层为D层 THEN 不匹配任何资金方，拒绝授信
- FM-004: IF 资金方当日已撮合额度/当日总可用额度>90% THEN 自动切换至备选资金方
- FM-005: IF 客户JWT（联合贷）资金方要求的担保比例>合同约定值 THEN 重新触发资金方竞价

### 3.2 资金方限额管理
- FM-006: IF 单一资金方在贷余额/该资金方总授信>80% THEN 触发预警，优先匹配其他资金方
- FM-007: IF 资金方审批通过率<50%（近7日内）THEN 暂停向该资金方推送客源，进行业务复盘
- FM-008: IF 资金方平均放款时效>4小时（近3日内）THEN 降低该资金方优先级
- FM-009: IF 资金方风险准备金覆盖率<合同约定值 THEN 暂停该资金方新增放款，直至补足

### 3.3 智能路由策略
- FM-010: 路由优先级：最优利率资金方（A层） > 审批通过率最高资金方（B层） > 最高可用额度资金方（C层）
- FM-011: IF 重资本资金方可用额度低于预警线 THEN 将部分A层客户导流至轻资本资金方
- FM-012: IF 多资金方同时可匹配 THEN 选择综合收益最高（利率价差+服务费+风险分担比例）的资金方

## 4. 风险定价规则 (PR)

### 4.1 基础定价
- PR-001: 定价基准 = 资金成本 + 风险溢价 + 运营成本 + 目标利润率
- PR-002: 资金成本按资金方出价确定；运营成本率固定2.5%；目标利润率3-5%
- PR-003: 风险溢价 = 预期损失率 × 1.5（含资本占用成本）
- PR-004: IF 客户为新客（首次借款）THEN 定价优惠1%（获客促销策略）

### 4.2 行为定价调整
- PR-005: IF 客户连续3期按时还款 THEN 自动降价0.5%（行为激励，利率逐期递减）
- PR-006: IF 客户为存量复贷且历史还款记录良好 THEN 利率可在基础定价上-1.5%
- PR-007: IF 客户使用APP推荐好友功能且推荐好友已成功借款 THEN 推荐人享受利率9折优惠1次
- PR-008: IF 借款金额>20万 THEN 利率可在基础定价上-0.5%（规模优惠）

### 4.3 促销定价规则
- PR-009: 双十一/618期间：全场利率9折（新客专享7折），单期限时3天
- PR-010: IF 客户连续3个月未借款（睡眠客户）THEN 触发唤醒利率优惠券（85折，有效期7天）
- PR-011: IF 客户在APP内浏览产品页面超过3次但未提交申请 THEN 触发弹窗利率优惠（9折，时效24小时）

## 5. 贷后监控规则 (PM)

### 5.1 异常交易监控
- PM-001: IF 放款后3天内借款人出现大额消费（>授信额的50%）THEN 追踪资金流向
- PM-002: IF 借款人放款后立即取现至非绑定账户 THEN 标记可疑，推送反欺诈
- PM-003: IF 借款人在放款后7日内多头申请其他平台 >3次 THEN 触发多头预警，调整风险评级
- PM-004: IF 借款人还款账户出现连续2次余额不足扣款失败 THEN 提前预警，转入M0关注

### 5.2 行为评分监控
- PM-005: IF 借款人行为评分（基于APP使用频率/信息披露/客服联络等）连续2个月下降 THEN 触发行为预警
- PM-006: IF 借款人手机状态变为关机/停机超过3天 THEN 触发失联预警，联系紧急联系人
- PM-007: IF 借款人工作单位发生变更（企业信息变更/社保断缴）THEN 标记为潜在风险，调整催收优先级
- PM-008: IF 借款人涉及法律诉讼（新增大额诉讼/被列为被执行人）THEN 立刻调至D层观察名单

## 6. 催收策略规则 (CL)

### 6.1 催收分案
- CL-001: IF 逾期1-5天（M0初期）THEN 智能短信+APP PUSH提醒（系统自动，无需人工介入）
- CL-002: IF 逾期6-15天（M0后期）THEN 短信+AI外呼+APP弹窗，每日1次提醒
- CL-003: IF 逾期16-30天（M0末期）THEN AI外呼频率提升至每日2次+人工外呼初步介入
- CL-004: IF 逾期31-60天（M1）THEN 转入专业电话催收团队；系统自动标记催收优先级
- CL-005: IF 逾期61-90天（M2）THEN 委外催收公司介入（委托费率按回收金额的8-15%计提）
- CL-006: IF 逾期>90天（M3+）THEN 委外催收+法务部同步启动；发起征信上报流程
- CL-007: IF 借款人失联（电话/短信均无法触达）超过7天 THEN 启动失联修复（查通话详单/社保/运营商数据）
- CL-008: IF 失联修复后仍无法触达超过15天 THEN 启动紧急联系人联络（按借款人预留顺序逐个联系）

### 6.2 催收调优规则
- CL-009: IF 借款人主动联系并承诺还款日期 THEN 给予7天宽限期，暂缓提高催收等级
- CL-010: IF 催收对象为A层客户（历史优质）THEN 催收语言风格为温和提醒，保持客户关系优先
- CL-011: IF 催收对象为D层客户（高风险）THEN 催收强度最大化，每日3次+多渠道触达
- CL-012: IF 借款人提出减免诉求 THNE 根据逾期天数给予差异化减免：M1减免≤10%罚息，M2减免≤20%，M3+≤30%（须主管审批）
- CL-013: IF 借款人全额结清逾期欠款 THEN 24小时内解除催收标记，评估信用恢复方案
- CL-014: IF 委外催收超过90天仍无进展 THEN 回收委外案件，转法务部进行法律诉讼
- CL-015: IF 经评估确定无法收回（借款人死亡/破产/失联超过6个月）THEN 启动核销流程，须风控总监审批

### 6.3 征信相关
- CL-016: IF 逾期>30天（M1+）THEN 向百行征信/朴道征信报送逾期记录
- CL-017: IF 逾期>90天（M3+）THEN 向人行征信系统上报不良记录
- CL-018: IF 借款人结清逾期欠款 THEN 在征信报告中标注"已结清"，不消除逾期记录但更新状态

## 7. 客户生命周期规则 (LC)

### 7.1 额度管理
- LC-001: IF 客户连续6个月正常还款且无逾期 THEN 自动提额（提额幅度10-30%，最高至原额度的150%）
- LC-002: IF 客户额度使用率<10%连续3个月 THEN 主动降额至实际需求的120%（释放资金方额度，提升资本效率）
- LC-003: IF 客户出现逾期30天以上（M1+）THEN 逾期贷款结清前暂停所有提现/借款权限
- LC-004: IF 客户出现M2+逾期后结清 THEN 降层处理（A→B, B→C, C→D），重新进入观察期

### 7.2 复贷与挽留
- LC-005: IF 客户当前无在贷余额且上一次贷款已结清 THEN 触发复贷邀请（优惠利率券+快速提额通道）
- LC-006: IF 客户贷款结清后30天内再次提交申请 THEN 简化流程（无需重复上传材料）
- LC-007: IF 客户已结清贷款且信用分层在此期间未下降 THEN 授信有效期内可直接支用（无需重新审批）
- LC-008: IF 睡眠客户（12个月未借款）TNE 重新评估信用状况（重新拉取征信+评估当前还款能力）
- LC-009: IF 睡眠客户回归后首次借款金额<5,000元 THEN 自动审批通道，新客优惠利率

### 7.3 客户升级
- LC-010: IF C层客户连续6期正常还款且当前无逾期 THEN 触发升级评估（C→B）
- LC-011: IF B层客户连续12期正常还款且当前无逾期 THEN 触发升级评估（B→A）
- LC-012: A层降级条件：IF A层客户出现逾期天数>30天 THEN 直接降至B层；IF A层客户出现M2+ THEN 直接降至C层
- LC-013: D层恢复条件：IF D层客户逾期结清后正常还款6个月且无新增逾期 THEN 恢复至C层初始评级

## 规则引擎架构

```
贷前规则（AC+CR）→ 资金路由（FM）→ 定价（PR）→ 放款 → 贷后监控（PM）→ 催收分案（CL）→ 生命周期（LC）
      ↓               ↓             ↓            ↓           ↓               ↓               ↓
  反欺诈引擎      审批决策引擎   智能定价引擎  放款引擎   监控预警引擎   催收策略引擎   额度管理引擎
```

### 规则优先级
- 黑名单规则（AC-009~AC-012）为最高优先级，一旦命中直接拒绝（硬拒绝），不进入后续阶段
- 反欺诈规则（AC）优先于审批规则（CR），反欺诈不通过不下发到审批阶段
- 资金路由规则（FM）优先于定价规则（PR），资金方确定后方可确定资金成本
- 生命周期的升降级规则（LC）在每期还款后批量执行，不实时干预借款流程
